# Making-Cartoons
I am remaking pictures using AI prompts to Cartoon style for a Birthday, Newborn Baby or another similar event.
For example using original photos to transform them. Like the one I upload here.

Създаване на изображения/карикатури с помощта на запитвания към Изкуствения Интелект, за да се направи анимиран вид за Рожден Ден, Новородено Бебе или друго подобно събитие.
Например, използвам оригинални изображения, за да ги трансформирам. Като това, което качих тук.
